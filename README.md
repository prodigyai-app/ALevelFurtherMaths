# Prodigy A Level Further Maths

Pearson Edexcel 9FM0 revision: 74 focused lessons covering Core Pure and all eight optional modules. Each has method explanations, a worked model and a separate transfer question with an indicative scheme. The standard exam is four 75-mark, 90-minute calculator papers: two Core Pure and two valid optional papers. Both Core Pure exams can assess the entire Core Pure content.

Route selection accepts two distinct first options or a first option with its matching second option. All modules remain available for browsing. The two 75-mark Core Pure revision papers reuse the lesson bank for consolidation; the eight shorter module assessments state their actual marks and durations and are not represented as full examination papers. Official materials are linked separately.

The real-function graph plotter and shared Maths keyboard are included. Complex-number and 2×2-matrix explorers provide additional interactive checks. Accounts, classes, assignment tracking and optional server-side AI marking use the shared platform; numerical checks alone never award every method mark.

Source data: course.json, generated from scripts/content.py and scripts/checks.py. Rebuild with python scripts/build.py. No Pearson questions are reproduced, no grade boundaries are invented, and there is no exam-board endorsement. These are revision lessons, not a replacement for a taught course.
